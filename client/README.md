# Rihlah Client (Next.js Frontend)

This is the frontend client for **Rihlah — Halal Journeys**, built with **Next.js 16 (App Router)**, **TypeScript**, **Tailwind CSS v4**, and **Base UI** primitives.

## Features
- **Curated Islamic & Halal Journeys**: Umrah & Ziyarat, Islamic Heritage, Halal Beach Resorts, Nature & Mountain retreats, and Family Halal tours.
- **Interactive Search & Filter**: Search by keyword, journey category, and max price with synced URL state.
- **Halal Assurance Badges**: Highlights 100% Zabiha halal dining standards and prayer-conscious itineraries.
- **CRUD Package Management**: Create, view, edit, and delete destination packages in MongoDB.
- **Optimized & Themed UI**: Emerald & warm gold palette, responsive navbar & footer, accessible dialogs, and smooth carousel.

## Getting Started

```bash
# From workspace root:
npm run dev:client

# Or from inside client/:
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. Ensure the backend server (`server/`) is running on port 8000.
